# FHIR-56637: Resource Access Provider is missing required search parameter combinations — align with IPA STU1

## Description

The IG states that Resource Access Provider conformance aligns with IPA STU1, but the search parameter requirements diverge in two ways:

Observation — IPA STU1 [CapabilityStatement-ipa-server]([http://hl7.org/fhir/uv/ipa/STU1/CapabilityStatement-ipa-server.html](http://hl7.org/fhir/uv/ipa/STU1/CapabilityStatement-ipa-server.html)) requires three SHALL combinations on `Observation`: `patient+category`, `patient+code`, and `patient+category+date`. This IG requires only the first.

Patient.identifier — IPA STU1 requires `identifier` in `[system]|[value]` form with both components. This IG permits any form, including valueless searches that return all patients (a privacy concern as well as a conformance gap).

Proposed resolution:

Update the search-parameter requirements in §3.5 (Resource Access) to mirror IPA STU1:

	- AllergyIntolerance — SHALL: `patient`. SHOULD: `patient+clinical-status`.

	- Condition — SHALL: `patient`. SHOULD: `patient+clinical-status`, `patient+category`, `patient+code`.

	- Observation — SHALL: `patient+category`, `patient+code`, `patient+category+date`. SHOULD: `patient+code+date`, `patient+category+status`.

	- DiagnosticReport — SHALL: `patient+category`. SHOULD: `patient+code`, `patient+category+date`.

	- MedicationRequest — SHALL: `patient`. SHOULD: `patient+intent`, `patient+status`.

	- MedicationDispense — SHALL: `patient`. SHOULD: `patient+status`.

	- MedicationStatement — SHALL: `patient`. SHOULD: `patient+status`.

	- Immunization — SHALL: `patient`. SHOULD: `patient+date`.

	- Encounter — SHALL: `patient`. SHOULD: `patient+date`, `patient+status`.

Tighten the `Patient.identifier` parameter to require `[system]|[value]` form, with both components present and non-empty.

Express the SHALL combinations in narrative + bullet form rather than CapabilityStatement composite-search-requirement extensions (those are difficult for non-FHIR-fluent procurement to read).

Update FSH CapabilityStatements to match.
