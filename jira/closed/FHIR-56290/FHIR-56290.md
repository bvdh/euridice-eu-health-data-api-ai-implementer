# FHIR-56290: Support for IPA docref

## Description

There need to be a way to request clinical notes from a ResourceAccessProvider. As the IG is based on IPA, the preferred option is to explicitly support [http://hl7.org/fhir/uv/ipa/OperationDefinition/docref](http://hl7.org/fhir/uv/ipa/OperationDefinition/docref).
