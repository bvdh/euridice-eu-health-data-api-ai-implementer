# FHIR-56710: Clarification about  EehrxfMhdDocumentReference  conformance

## Description

Clarify that:

	- Conformance to EehrxfMhdDocumentReference is not strictly required, or is one possible profile

	- Additional DocumentReference.category elements MAY be used beyond those defined in the profile
