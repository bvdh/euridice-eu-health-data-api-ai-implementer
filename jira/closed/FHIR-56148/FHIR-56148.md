# FHIR-56148: Info about availability of Xt-EHR deliverables should be time-based

## Description

The section ends with text "Note: Xt-EHR deliverables are not yet publicly released."

It would be better to express this in a format "Note: at the time of writing of this section (March 2026), the Xt-EHR deliverables are not yet publicly released."

 

So that the page stays correct even after Xt-EHR deliverables are released, without a need for an immediate change.
