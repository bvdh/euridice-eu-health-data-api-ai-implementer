# FHIR-56851: creation search parameter

## Description

The CapabilityStatement does not include the creation search parameter for DocumentReference.

	- The creation parameter (i.e., content.attachment.creation) is often more relevant for document discovery than DocumentReference.date, which represents metadata indexing time

	- Relying only on date may lead to incorrect or suboptimal search behavior

	- It is unclear whether this omission is intentional or accidental, and similar gaps may exist in other CapabilityStatements

Proposed Change:

	- Add support for the creation search parameter in the DocumentReference search definition

	- Clarify its role, e.g.:

“The creation search parameter SHOULD be supported to enable filtering based on the clinical document creation time.”

	- Review and update other CapabilityStatements to ensure consistent inclusion of relevant search parameters
