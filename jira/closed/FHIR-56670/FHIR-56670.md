## Resolution

- Status: Applied
- Resolution: Persuasive

Replace undefined resource PUSH terminology with resource publication, defined as submitting individual clinical FHIR resources to another system for incorporation. Distinguish it from ITI-105 document publication. Retain the implementation considerations and out-of-scope boundary. Describe FHIR Subscriptions informatively as notification followed by retrieval, not an ingestion contract; remove the unsupported Netherlands claim. Preserve the resourceExchange.html URL. The implementation is proposed in the correction PR and is not yet merged or Applied. Implementation proposal: [https://github.com/euridice-org/eu-health-data-api/pull/101](https://github.com/euridice-org/eu-health-data-api/pull/101)
