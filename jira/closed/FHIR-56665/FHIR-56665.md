# FHIR-56665: Editorial: enumerate which architecture-diagram arrows are in-scope for this IG

## Description

[usecase-cross-border-ncp.html](https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/usecase-cross-border-ncp.html) line 25 says "This IG defines this API" but doesn't say which arrows in the architecture diagram correspond. List the in-scope arrows, or label them on the diagram.

## Resolution

- Status: Applied
- Resolution: Persuasive

The Cross-Border via NCP overview identifies the interface defined by this IG as the final step: national infrastructure (or the NCP itself) querying EHR systems. The architecture distinguishes NCP-to-NCP exchange, Member State routing and the EHR API boundary. This satisfies the requested identification of the in-scope arrow. Evidence is already on main at 98a084d3a7172d8d590466327098f72afaa14c3c. A separate local proposal improves diagram legibility; it is not a prerequisite for this correction. Implementation proposal: [https://github.com/euridice-org/eu-health-data-api/pull/101](https://github.com/euridice-org/eu-health-data-api/pull/101)
