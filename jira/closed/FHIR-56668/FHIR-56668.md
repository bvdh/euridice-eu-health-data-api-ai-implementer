# FHIR-56668: Add Priority Categories to the IG menu (currently only reachable via Next-button navigation)

## Description

The Priority Categories pages ([priority-categories.html](https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/priority-categories.html) and the per-category pages it indexes) are reachable only by clicking "Next" from Regulatory Background. Since these pages define requirements, implementers will miss them.

Proposed resolution:

Add a "Priority Categories" menu heading in sushi-config.yaml so the index page (and ideally the per-category pages) appear in the IG's top navigation.

Reporter(s): Aaron Mahr, Epic
