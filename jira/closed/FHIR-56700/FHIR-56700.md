# FHIR-56700: Custodian should be optional

## Description

The EEHRxF MHD DocumentReference Profile defines .custodian 1..1 (whereas the IHE MHD integration profile specifies an optional organization reference). Since no MS flag is set either, the cardinality should be 0..1.
