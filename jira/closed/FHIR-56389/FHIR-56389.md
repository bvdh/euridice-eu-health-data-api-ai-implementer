# FHIR-56389: Ressource Access (Add note for EHDS)

## Description

QEDm, mXDE, and IPA are referenced in this section as FHIR resource access patterns. These profiles are technically sound and represent good practices for implementers looking to go beyond simple document-level access.

However, it is important to clarify the relationship of resource access to the EHDS regulatory framework: the resource access is out of scope for EHDS at the present time. The EHDS regulation does not reference them as requirements or recommendations at this stage.

Including the corresponding profiles without this clarification risks misleading implementers seeking EHDS compliance, creating the false impression that these profiles are required for regulatory conformance.

Proposed resolution :

We recommend adding a clear note in the implementation guide
