# FHIR-56635: IPA vs QEDm references

## Description

Section 3.5.3 (reference to “Query Existing Data mobile”)

Issue:

The text references:

“Query Existing Data mobile, where compatible with IPA.”

If the reference is IPA we should not create confusion with conditional IHE QEDm conformance.

Proposed Change:

Remove the reference to IHE QEDm from this section and rely solely on IPA. In case add a note about IHE QEDm
