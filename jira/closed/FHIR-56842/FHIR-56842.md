# FHIR-56842: Resolve page inaccuracies

## Description

The page presents some ambiguities and inaccuracies:

	- The role of the National Infrastructure (NI) with respect to EHR systems is not clearly defined and may be misleading. The current description may suggest that NI replaces or encapsulates EHR systems, while in reality NI typically acts as a mediator or gateway interacting with multiple underlying systems.

	- The link provided for NCP-to-NCP communication specifications is incorrect or not functional.

Proposed Change:

	- Revise the description of the National Infrastructure to clarify its role, e.g.:

“The National Infrastructure acts as a gateway or coordination layer that interfaces with one or more underlying systems (e.g., EHR systems), rather than being a single monolithic system.”

	- Fix the link to the correct specification: [https://fhir.ehdsi.eu/ncp-api/](https://fhir.ehdsi.eu/ncp-api/)

## Resolution

- Status: Applied
- Resolution: Persuasive

Clarify that national infrastructure is a logical collection of components and that its gateway or coordination components interface with underlying EHR systems. Preserve the simplified diagram and label the API boundary on the final arrow. Both specification hosts resolve, so do not characterize the existing link as broken; use the requested fhir.ehdsi.eu/ncp-api destination for the public guide rather than build-fhir.ehdsi.eu development build. The implementation is proposed in the correction PR and is not yet merged or Applied. Implementation proposal: [https://github.com/euridice-org/eu-health-data-api/pull/101](https://github.com/euridice-org/eu-health-data-api/pull/101)
