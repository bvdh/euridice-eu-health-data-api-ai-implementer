# FHIR-56458: Missing ePrescription and eDispensation

## Description

In paragraph 1.2 "Scope" ([Home - EU Health Data API v1.0.0-ballot](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/index.html)).

"This IG excludes ePrescription and eDispensation workflow transactions, user-level authorization, audit logging formats, and bulk data export."

Is there any plan to update this IG with the workflow (and the transactions) of ePrescription and eDispensation? IHE MPD covers many situation and it would be nice to cover the EHDS use cases only (Articles 3, 4, 5, 7, 11, 12, 23, 48).

## Resolution

- Status: Resolved - No Change
- Resolution: Considered - Question answered

ePrescription and eDispensation workflow transactions remain outside the scope of this API IG. Reading medication data, including MedicationRequest, MedicationDispense and MedicationStatement, is covered through resource access; reading these resources does not implement the prescribing and dispensing workflow. Clarify this distinction and point readers to the [HL7 EU Medication Prescription and Dispense IHE Transactions page](https://hl7.eu/fhir/mpd/transactions.html), which provides informative guidance on combining medication content with IHE MPD transactions. That guidance does not replace existing national or MyHealth@EU transaction requirements. Further ePrescription/eDispensation API profiling may be addressed in a future dedicated implementation guide, consistent with the cross-IG direction towards priority-category-specific API guides.
