# FHIR-56149: Requirements Framework table is hard to read

## Description

The table is somewhat hard to read. The headings Level of Technical Detail and Example are too close together and too far from content to make it immediately clear where the heading ends and the next one begins.

It would benefit from some separating lines, at least between table rows.
