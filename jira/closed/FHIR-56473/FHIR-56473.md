# FHIR-56473: ePrescription and eDispensation

## Description

In paragraph 2.1.0.11.2 "Content vs Echange" ([Regulatory Anchors - EU Health Data API v1.0.0-ballot](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/regulatoryAnchors.html)).

"For medication data, this IG covers reading MedicationRequest and MedicationStatement as individual resources via resource exchange. The ePrescription and eDispensation workflow transactions (prescribing, dispensing) are out of scope and handled by [IHE MPD](https://profiles.ihe.net/PHARM/MPD/index.html)".

Is there any plan to update this IG with the workflow (and the transactions) of ePrescription and eDispensation? IHE MPD covers many situation and it would be nice to cover the EHDS use cases only (Articles 3, 4, 5, 7, 11, 12, 23, 48). These use cases were defined during the CapacityHD sessions "Preparing for the EEHRxF (Interoperability and Interoperability Testing) continued: Towards an EHDS Use Cases Catalogue for Primary Use". There are probably some missing.

## Resolution

- Status: Resolved - change required
- Resolution: Not Persuasive with Modification
- Resolution Vote: 9-0-0
- Vote Date: 2026-10-21

Keep ePrescription and eDispensation workflow transactions outside this API IG. Clarify that access to MedicationRequest, MedicationDispense and MedicationStatement is covered as resource access, whereas prescribing and dispensing workflows require domain-specific transaction definitions. Direct readers to the [HL7 EU Medication Prescription and Dispense IHE Transactions page](https://hl7.eu/fhir/mpd/transactions.html) for informative IHE MPD guidance; this does not mandate replacement of national or MyHealth@EU transactions. EHDS-specific workflow/API profiling may be addressed in a future dedicated ePrescription/eDispensation API implementation guide, consistent with the cross-IG direction towards priority-category-specific API guides.
