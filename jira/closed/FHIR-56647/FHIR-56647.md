# FHIR-56647: Remove "Resource Publisher" references — actor not defined in this IG

## Description

The IUA Actor Groupings section of authorization.html reads:

Document/Resource Publisher: IUA Authorization Client

Document/Resource Consumer: IUA Authorization Client

Document/Resource Access Provider: IUA Resource Server (required) + IUA Authorization Server (if internal)

No "Resource Publisher" actor exists in this IG — there is no FSH definition and actors.html does not list it. The label is a phantom reference that an implementer cannot satisfy.

Proposed resolution:

Remove the "/Resource Publisher" half of each label so the bullets refer only to defined actors: Document Publisher, Document Consumer, Document Access Provider. Resource-level publishing is not yet in scope for this version of the IG.

Reporter(s): Kyle Bennett, Epic
