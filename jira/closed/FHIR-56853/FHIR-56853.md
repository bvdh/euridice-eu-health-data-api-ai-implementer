# FHIR-56853: type search parameter : SHALL → SHOULD

## Description

The CapabilityStatement defines:

	- type search parameter as SHALL

	- Does not include the creation search parameter

This may be too restrictive and not fully aligned with practical document discovery:

	- Requiring type as SHALL limits flexibility, especially where category-based search is used

	- The creation parameter (document creation time) is often more relevant than date (metadata indexing time)

Proposed Change:

	- Change the requirement level for type search parameter:

type: SHALL → SHOULD

	- Add the creation search parameter as SHOULD, e.g.:

creation: SHOULD (to support filtering based on document creation time)
