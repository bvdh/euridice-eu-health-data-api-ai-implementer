# FHIR-56641: Section 3.5.6 Core Resources: add missing eu core profiles

## Description

Section 3.5.6 Core Resources

 

The list of resources in the section appears incomplete with respect to the profiles defined in the HL7 Europe Core. Several important resources (e.g., Practitioner, PractitionerRole, Organization, Location, etc.) are not included, despite being part of the core data model and often required for proper interpretation of clinical data.

Proposed Change:

Extend the list of resources to include all relevant resources defined in the HL7 Europe Core, for example:

	- Practitioner

	- PractitionerRole

	- Organization

	- Location

	- (and other applicable EU Core resources)

Alternatively:

	- Explicitly state that all HL7 Europe Core resources are in scope, even if not individually listed
