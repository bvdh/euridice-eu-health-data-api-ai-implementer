# FHIR-56714: DocumentReference should be based on MHD Minimal OR Comprehensive to handle the MADO envelope

## Description

The IG currently derives EehrxfMhdDocumentReference from IHE.MHD.Minimal.DocumentReference. This does not fit the needs of the MADO profile, based on the search-parameter and metadata analysis from the MADO subteam. Moving to MHD Comprehensive fits the MADO use case and allows a single conformance-path target for both this IG and the MADO specification.

Proposed resolution:

Change Parent of EehrxfMhdDocumentReference from IHE.MHD.Minimal.DocumentReference to IHE.MHD.Comprehensive.DocumentReference.

The MADO profile should be the canonical source of the MHD DocumentReference shape for imaging, and that profile fits within MHD Comprehensive. The API IG should target MHD Comprehensive to support this — and potentially other priority-category use cases.
