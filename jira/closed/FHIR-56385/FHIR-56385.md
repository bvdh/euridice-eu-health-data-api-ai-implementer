# FHIR-56385: Health Data Access Service not limited to Consumer

## Description

It seems like the page for the Health Data Access Service Use Case is currently limiting the HDAS for a patient to a consumer actor.

But according to articles 5 (insertion) & 6 (rectification) an HDAS has to support source/producer/publisher functionality as well.

The request of this ticket is therefore, to add this actor to this page and to adapt the various chapter on it accordingly.
