# FHIR-56478: Definition of the HDAS

## Description

In paragraph 4.3 "Use Case - Health Data Access Service" ([Use Case - Health Data Access Service - EU Health Data API v1.0.0-ballot](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/usecase-health-data-portal.html)), the definition of HPAS should be more precise. For exemple:

"Health Data Access Services are provided by Member States to natural persons or their representative for accessing their health data. These services can be provided as a web portal, an API or other services. These services are connected to the Electronic Health Record (EHR) of the natural person. The infrastructure behind the HDA Services is specific to each country (see [Member State Architectures - EU Health Data API v1.0.0-ballot](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/member-state-architectures.html)).

- Status: Applied
- Resolution: Persuasive
- Resolution Vote: Reinhard Egelkraut / Katie Reynolds: 7-0-1
