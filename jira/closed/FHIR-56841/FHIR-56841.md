# FHIR-56841: National Infrastructure as a single actor

## Description

The use case models the National Infrastructure as a single actor. This is potentially misleading because, in reality, the national infrastructure typically consists of multiple systems, including:

	- EHR systems producing and managing health data

	- National services (e.g., registries, gateways)

	- Other supporting components

Representing it as a single actor may oversimplify the architecture and obscure important interoperability boundaries.

Proposed Change:

Revise the description and/or diagram to clarify that the National Infrastructure is a logical grouping of multiple systems, for example:

“The National Infrastructure represents a set of systems, including EHR systems and national services, which together provide access to health data.”
