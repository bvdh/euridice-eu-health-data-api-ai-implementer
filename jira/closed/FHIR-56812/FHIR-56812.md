# FHIR-56812: Add high level use cases

## Description

To allow users of the specification to better understand how the defined actors and transactions are meant to be deployed, following the IHE Methodology, high-level business use cases need to be added together with a mapping of the actions in the use cases to the defined actors and transactions.

It is important that these use cases address the role of the various "EHR system" type products, not only the myHealth@EU and member state infrastructure.

An example of a use case is available at
