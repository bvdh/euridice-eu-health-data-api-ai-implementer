# FHIR-56839: Revise text (e.g. usage of NCP)

## Description

1)

The term “NCP” is used throughout the page, which is not sufficiently precise in the healthcare context. In the EU cross-border health domain, the correct term is NCPeH (National Contact Point for eHealth).

Proposed Change:

Replace all occurrences of “NCP” with “NCPeH”, e.g.:

“cross-border NCP” → “cross-border NCPeH”

2)

The sentence:

“NCPs communicate with each other via the MyHealth@EU network”

uses imprecise terminology:

	- “NCPs” should be NCPeHs

	- “network” is not the correct term; MyHealth@EU is an infrastructure

## Resolution

- Status: Applied
- Resolution: Persuasive

Define National Contact Point for eHealth (NCPeH) once and state that this guide uses the shorter NCP thereafter. Replace MyHealth@EU network with infrastructure in the cross-border example and its duplicated implementation overview. Preserve page URLs and existing NCP shorthand. This accepts the precision concern with a concise terminology convention rather than expanding every occurrence. The implementation is proposed in the correction PR and is not yet merged or Applied. Implementation proposal: [https://github.com/euridice-org/eu-health-data-api/pull/101](https://github.com/euridice-org/eu-health-data-api/pull/101)
