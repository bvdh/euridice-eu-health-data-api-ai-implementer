# FHIR-56856: Inconsistency between narrative and profile

## Description

6.0.29 Structures: Resource Profiles

The narrative states:

“category: This IG does not constrain category. Usage is determined by content IGs and implementation needs.”

However, the profile constrains DocumentReference.category to 0..1, which is inconsistent with this statement:

	- Limiting cardinality to 0..1 effectively constrains usage

	- In practice, multiple categories may be needed (e.g., classification by domain, workflow, or use case)

Proposed Change:

Align the profile with the narrative by:

	- Removing the restriction and allowing multiple categories (e.g., 0..*)
