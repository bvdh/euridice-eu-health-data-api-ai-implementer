# FHIR-56477: Definition of the HPAS

## Description

In paragraph 4.2 "Use Case - Health Professional Access Service" ([Use Case - Health Professional Access Service - EU Health Data API v1.0.0-ballot](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/usecase-health-professional-portal.html)), the definition of HPAS should be more precise. For exemple:

"Health Professional Access Services are provided by Member States to health professionals for accessing the health data of their patients. These services can be provided as a web portal, an API or other services. These services are connected to the Electronic Health Record (EHR) of the natural person. The infrastructure behind the HPA Services is specific to each country (see [Member State Architectures - EU Health Data API v1.0.0-ballot](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/member-state-architectures.html)).
