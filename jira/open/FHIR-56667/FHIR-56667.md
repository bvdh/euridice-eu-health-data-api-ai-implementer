# FHIR-56667: Rename "Open Issues" → "Input Requested"; document the relationship to GitHub issues and Jira

## Description

The "Open Issues" page is curated, not exhaustive, and the page doesn't describe its relationship to GitHub issues and Jira. Readers expect a complete bug/issue list; this page isn't one.

Proposed resolution:

	- Rename to "Input Requested" (or similar) to signal that the page lists issues for which editors are soliciting input, not the full open-issue set.

	- Add a short paragraph: GitHub issues are the bug/feature tracker; Jira is the formal-comment channel during ballot; this page surfaces a curated subset needing community input.

	- State explicitly that the page is curated, not exhaustive.

Reporter(s): Aaron Mahr, Epic
