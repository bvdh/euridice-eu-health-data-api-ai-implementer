# FHIR-56640: Derived Resources: provenance target

## Description

Derived Resources

 

The current text indicates that derived resources SHOULD link to the source DocumentReference. This is too restrictive, as derived resources may originate from:

	- A DocumentReference (metadata + attachment), or

	- A FHIR Document Bundle (Bundle.type = "document")

 

Proposed Change:

Revise the statement to include both possibilities, e.g.:

“Derived resources SHOULD include a reference to their source, which may be a DocumentReference or a FHIR Document Bundle (Bundle.type = 'document').”
