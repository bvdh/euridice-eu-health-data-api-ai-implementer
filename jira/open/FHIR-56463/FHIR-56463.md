# FHIR-56463: Right to insert information

## Description

In paragraph 2.1.0.5 "Xt-EHR Deliverable 5.1" ([Regulatory Anchors - EU Health Data API v1.0.0-ballot](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/regulatoryAnchors.html)).

According to Article 5, "be able to receive" means also that an EHR system which implements an health data access service (HDAS) through an API should be capable to import health data in the EHR of a natural person. The interoperability componenent of such system (Consumer ?) should provide an inbound connector to receive data from another system, unsolicited. I suggest adding a row in the table:

(Article 5 "right to insert information", Consumer: Receive health data, Consumer)

A new transaction should also be added in the Figure "Query-based Exchange Model".
