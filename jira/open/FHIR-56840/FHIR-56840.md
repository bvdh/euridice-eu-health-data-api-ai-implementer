# FHIR-56840: MyHealth@EU not limited to the pull mode

## Description

The description of MyHealth@EU services in the example focuses on a query/retrieve interaction but does not explicitly state this. This may be misleading because MyHealth@EU also consider push-based workflows, not only query-based ones.

Clarify the scope of the example, e.g.:

“This example refers to the Document Query and Retrieve interaction pattern within MyHealth@EU. Other interaction patterns, including push-based exchanges, are also supported but are not illustrated here.”
