# FHIR-56686: Clarification of the Document Access Provider role

## Description

In the “Requirement Actor Definitions” section of the implementation guide ([https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/artifacts.html#requirements-actor-definitions](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/artifacts.html#requirements-actor-definitions)), it is stated that the actor “EEHRxF Document Access Provider” receives and serves documents. This implies that this actor is involved in both submission and retrieval workflows. However, when looking at the capability statement associated with this actor, there is no mention of aspects related to the publication workflow. Only aspects related to the retrieval workflow are addressed.

Proposed resolution :

The most effective solution appears to introduce a new Document Access Recipient actor. Therefore, it would be necessary to define a capability statement for this additional actor.

In addition, the definition of the Document Access Provider actor needs to be rectified.
