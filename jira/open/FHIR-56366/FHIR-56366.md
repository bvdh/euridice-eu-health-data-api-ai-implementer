# FHIR-56366: Revise Requirements Table

## Description

API Requirements (Access Provider), Technical Spec column

It is unclear whether all listed requirements in the Technical Spec column are fully specified within this Implementation Guide - as I expected - or not.

If they are, please refer to the specification/transaction/part in this guide that cover this requirement (even if based on global specifications).

If not - but in that case there is no reason for this guide - make explicit that that requirement is covered by an external or global standard.

Clarify the scope of the Implementation Guide by either:

	- Explicitly stating that all listed requirements are fully covered by this guide, or

	- Clearly indicating where requirements rely on external/global standards (with references), e.g.:

“Where not explicitly specified in this guide, requirements refer to applicable global standards or specifications.”
