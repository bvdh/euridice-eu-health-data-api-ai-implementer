# FHIR-56631: revise 3.4.3.3.1 EHDS Priority Categories and Type

## Description

Section 3.4.3.3.1 EHDS Priority Categories and Type

	- Issue:

The section defines a limited set of LOINC codes as DocumentReference.type for EHDS priority categories. This approach appears overly restrictive and may:

	- - Limit the use of more granular or context-specific document types

 - Conflate document classification (category) with document type

 - Prevent valid search strategies based solely on DocumentReference.category

 - Conflict with content IGs that define their own document typing

The only potential exception is Patient Summary, where a fixed type code may be appropriate to ensure consistent identification.

	- Proposed Change:

Revise the section to:

 - Allow document discovery using category without constraining type

 - Treat the listed LOINC codes as examples or baseline values, not exclusive constraints

 - Clarify the distinct roles of DocumentReference.category and DocumentReference.type

 - Retain a possible constraint only for Patient Summary, if required for interoperability
