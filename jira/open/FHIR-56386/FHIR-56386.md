# FHIR-56386: Health Professional Access Service Authorization

## Description

In 4.2.4 Technical Flow the Authorization part just mentions SMART as a requirement.

The request of this ticket is to add IHE IUA as well since it is the basis of the Authorization described in the EU Health Data API specification.
