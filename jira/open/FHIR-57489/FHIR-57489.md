# FHIR-57489: Clarity missing on actors and transactions for the medication priority categories

## Description

Euridice is the health data API IG for the EHDS priority categories. However, for medication priority categories (ePr/eDi) there seem to be some inconsistencies.

There is a statement on medications being resource access only. Under [https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/CapabilityStatement-EEHRxF-ResourceAccessProvider.html#resource-flexibility-ipa-alignment](https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/CapabilityStatement-EEHRxF-ResourceAccessProvider.html#resource-flexibility-ipa-alignment) applicable resources (MedicationRequest + MedicationDispense ) are listed, and thus declares support for the medication priority categories.

 

But there is a partly contradicting statement regarding to the priority categories for medications in the following section [https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/priority-categories.html#priority-categories-and-exchange-patterns](https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/priority-categories.html#priority-categories-and-exchange-patterns). In this section both medication categories are missing from the list of priority categories, while the subsequent paragraph states “Medication data and ePrescription/eDispensation: Reading medication resources (MedicationRequest, MedicationStatement) is resource access, handled by this IG. “. In this statement MedicationDispensation is not included, although it is a priority category. This may create confusion on whether Euridice is referring to MPD as the go to IG specifically for access to the priority category Electronic Dispensation. We think that this would be a bad solution, as security model, search parameters etc would then be different from Euridice health data api. i.e. not aligned with the other priority categories.

A comment: For content, this section refers to [https://confluence.hl7.org/spaces/HEU/pages/358255737/Implementation+Guides](https://confluence.hl7.org/spaces/HEU/pages/358255737/Implementation+Guides), but in this list medication priority categories are missing, assuming the intention was to list all priority categories, as it only lists MPD explicitly (which is not the EU health data API for the medication priority categories. Does this table need to updated to explicitly declare how HL7 supports the eP7eD priority categories through resource profiles (which ones).

Proposal: add MedicationDispensation to the list of resources of section [https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/priority-categories.html#priority-categories-and-exchange-patterns](https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/priority-categories.html#priority-categories-and-exchange-patterns).
