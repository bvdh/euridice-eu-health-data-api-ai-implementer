# FHIR-56621: Remove global constraint on type

## Description

Document Search Strategy paragraph

 

	- The statement:

“This IG constrains type for document discovery but leaves category to content IGs and implementations.”

may introduce inappropriate constraints. Constraining DocumentReference.type at this level could:

	- - Limit flexibility across different use cases and domains

 - Conflict with existing content IGs that define their own document classification

 - Create inconsistencies if multiple content IGs are used

	- Proposed Change:

Reconsider the constraint on DocumentReference.type, and instead:

	- - Either leave type to be defined by content IGs, or

 - Clearly justify and scope the constraint (e.g., only for specific use cases)

Example wording:

“This IG does not globally constrain DocumentReference.type. The document type SHALL be defined by the applicable content implementation guide.”
