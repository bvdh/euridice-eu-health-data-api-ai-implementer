# FHIR-56638: revise Section 3.5.6 Core Resources

## Description

Section 3.5.6 Core Resources

	- Issue:

The text states:

“Data models inherit from HL7 Europe Core. Required search parameters are from International Patient Access (IPA).”

However:

	- - Not all mentioned resources appear to be defined or profiled in the HL7 Europe Core

 - There is no explicit reference or link to the specific HL7 Europe Core profiles being used

 - This may create ambiguity about which profiles are actually in scope

	- Proposed Change:

Clarify and make references explicit, e.g.:

“Where available, data models inherit from HL7 Europe Core profiles (see [link to EU Core profiles]). Resources not covered by HL7 Europe Core SHALL follow the base FHIR specification or applicable implementation guides. Required search parameters are aligned with the International Patient Access (IPA) guide.”

Additionally:

	- - Provide a direct link to the HL7 Europe Core profiles

 - Optionally list which resources are covered vs not covered
