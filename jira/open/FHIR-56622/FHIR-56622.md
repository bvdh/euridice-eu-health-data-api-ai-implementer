# FHIR-56622: Revise EHDS type codes

## Description

EHDS Priority Categories and Type Codes paragraph

 

The table defines specific LOINC codes as DocumentReference.type for each EHDS priority category. While these codes are valid examples, this approach may be too restrictive:

	- - It may prevent the use of more granular or specific document types

 - It conflates document classification (category) with clinical document type (type)

 - It may not accommodate variations required by different content IGs

	- Proposed Change:

Clarify that:

	- - The listed codes are examples or baseline codes, not an exhaustive or exclusive set

 - More specific DocumentReference.type codes MAY be used where appropriate

 - DocumentReference.category SHOULD be used to represent broader document classes (e.g., Patient Summary, Discharge Report)

Example wording:

“The listed LOINC codes represent common baseline document types for EHDS priority categories. More specific document types MAY be used where defined by applicable content IGs. DocumentReference.category SHOULD be used to represent the broader document class.”
