# FHIR-56699: Foundational IHE Profiles CT, ATNA

## Description

The foundational IHE profile CT should be a recommendation. The time service of the national infrastructure in Germany requires Network Time Protocol version 4. In contrast, the IHE CT profile requires version 3.

IHE ATNA is referenced for secure transport (TLS). This implies the Authenticate Node [ITI-19] transaction. A note might be helpful that the Record Audit Event [ITI-20] transaction is optional.

## Resolution

- Status: Triaged
- Resolution: Persuasive with Modification

Recommend IHE CT Time Client grouping for SMART Authorization Servers and FHIR Resource Servers, while retaining the CT grouping required by IHE IUA for its server roles. Encourage NTPv4 use without changing applicable CT conformance requirements, and link the server ActorDefinitions to this guidance and the relevant specifications. This IG no longer requires ATNA.
