# FHIR-56628: Support binary retrieval (PDF)

## Description

Section 3.4.3.2 Document Content

 

	- Issue:

The Document Content table does not explicitly include binary formats (e.g., PDF). This may suggest that only FHIR and DICOM-based representations are supported.

	- Proposed Change:

Either:

	- - Add an explicit row for binary formats, e.g.:

Content Pattern
attachment.contentType
Retrieved Content
Example

Binary Document
application/pdf
Binary resource (PDF)
/Binary/[id]

and/or

	- - Add a general note:

“Additional formats, including binary representations (e.g., PDF), may be used. Consumers select the supported representation based on contentType.”
