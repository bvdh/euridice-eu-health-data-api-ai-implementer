# FHIR-56633: Reference to specialized transactions

## Description

Issue:

The guide defines specific constraints and additional rules on existing (IHE) transactions. As a result, these transactions are no longer identical to their original definitions but represent specializations of them.

However, the current naming does not clearly reflect this

Proposed Change:

Update the naming convention of the transactions to explicitly reflect their specialization, for example:

	- “EHDS Publish Document” instead of reusing the base transaction name or

	- “EHDS Retrieve Document”

	- “EHDS Patient Discovery” (if applicable, though constrained as per other comments)
