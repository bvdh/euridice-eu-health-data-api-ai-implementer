# FHIR-56581: IUA & SMART Differences

## Description

Chapter 3.2.8 IUA and SMART Backend Services states that "...Where IUA and SMART Backend Services requirements differ, this IG follows SMART." and afterwards lists one example.

Please, add all the differences between IUA and SMART that are relevant for this IG, not just one example.

## Resolution

- Status: Triaged
- Resolution: Persuasive

The Authorization page has been expanded to compare IHE IUA and SMART App Launch across discovery, scope model, context, interactive use, and system-to-system use (see authorization.md). Its detailed protocol sections also describe client authentication, discovery metadata, access-token handling, and CORS, and clarify how deployments select the applicable profile per endpoint and environment. These changes are present in [PR #99 — Eu health data api ballot recon authorization](#99 — Eu health data api ballot recon authorization)([https://github.com/euridice-org/eu-health-data-api/pull/99](https://github.com/euridice-org/eu-health-data-api/pull/99)).
