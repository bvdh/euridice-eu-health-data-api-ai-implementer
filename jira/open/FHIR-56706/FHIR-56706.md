# FHIR-56706: Revise Section 4.1.5.4

## Description

The text refers to:

“using IHE MHD ITI-67 (Find Document References) transaction”

This suggests use of the generic IHE transaction, while the guide actually defines constrained/specialized transactions. This may create confusion about Which transaction definition should be implemented

Proposed Change:

Update the wording to reference the transaction as defined in this Implementation Guide, e.g.:

“using the Find Document References transaction as defined in this guide (aligned with IHE MHD ITI-67)”

 

(2)

	- The example uses the format code:

urn:ihe:pcc:ips:2020

This code refers to the IPS CDA template (templateId 2.16.840.1.113883.10.22.1.1) and may therefore be misleading if the intention is to represent a FHIR-based IPS or a more general Patient Summary context.

	- Proposed Change:

Review and correct the formatCode used in the example
