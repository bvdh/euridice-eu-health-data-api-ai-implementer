# FHIR-56558: Capability Discovery for Interoperability Profiles

## Description

On 3.1 Capability Discovery only the document related implementation guides are listed as Priority Category Support.

Xt-EHR D8.1 introduced the scoped conformance approach with various Resource Interoperability Profiles. This should be reflected on this page as well, including some examples.
