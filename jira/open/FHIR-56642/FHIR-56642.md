# FHIR-56642: Improves clarity and neutrality

## Description

The sentence:

“how existing IHE profiles and other specifications”

is unbalanced and may unintentionally prioritize IHE profiles over other relevant standards (e.g., HL7 implementation guides).

Proposed Change:

Revise the sentence to use a more neutral and inclusive phrasing, e.g.:

“how existing specifications, e.g. IHE profiles or HL7 implementation guides (e.g. IPA)”
