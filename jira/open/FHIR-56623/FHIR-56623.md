# FHIR-56623: Revise dual DocumentReference pattern

## Description

Document Content / general guidance (similar to Imaging note)

The guide provides a note for imaging using a dual-DocumentReference pattern (FHIR + DICOM KOS), but similar guidance is not provided for other document types. This may limit interoperability or lead to inconsistent handling of alternative representations (e.g., structured vs rendered documents).

 

Add a general note extending the dual-representation pattern to other document types, e.g.:

“Documents may use a dual-DocumentReference pattern to represent alternative formats of the same content. For example, a structured FHIR document may be accompanied by a rendered version (e.g., PDF). These DocumentReferences can be linked using relatesTo.transforms. Consumers select the representation they support based on contentType.”

 

check however consistency with the approach described in the Imaging Guide
