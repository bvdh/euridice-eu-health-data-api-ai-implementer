# FHIR-56625: FHIR ImaginStudy usage

## Description

Section 3.4.3.2 Document Content

	- Issue:

The current table in the Document Content section does not include FHIR ImagingStudy as a possible representation for imaging manifest content. This omission may lead implementers to assume that only DICOM KOS is supported.

	- Proposed Change:

Add a row to the table for FHIR ImagingStudy, for example:

Content Pattern
attachment.contentType
Retrieved Content
Example

FHIR Imaging Manifest
application/fhir+json or application/fhir+xml
FHIR ImagingStudy
/ImagingStudy/[id]

Adjust wording as needed to align with the rest of the section.
