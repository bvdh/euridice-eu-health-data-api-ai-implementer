# FHIR-56687: Retrieve of bundle type resources

## Description

The Capability Statement section for the Document Consumer actor does not mention the ability to retrieve Bundle-type resources. However, this is explicitly mentioned in the Document Exchange chapter (3.4.3.2).

Proposed resolution :

The list of retrievable resource types should therefore be updated to include the Bundle type.
