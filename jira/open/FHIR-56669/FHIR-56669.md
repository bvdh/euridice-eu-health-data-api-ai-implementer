# FHIR-56669: Editorial: resource-access page — collapsible visual, example queries, mXDE reference, IPA link versions

## Description

Four small fixes on [resource-access.html](https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/resource-access.html):

	- The HTML <details> "Click for more" element on the Resource Publisher note has no visual affordance and reads as broken. Replace with a normal callout linking to the Resource Publisher actor description.

	- The example queries include parameters not required by the IG (the SHALL/SHOULD table has been tightened). Trim examples to required params, or label them "optional".

	- The IHE mXDE note is ambiguous: mXDE isn't listed among aligned specifications at the top of the page, so its conformance level is unclear. Clarify whether mXDE is informational, SHOULD, or out-of-scope. Consider linking to a specific structure definition rather than the spec landing page.

	- IPA links use the current build URL. Update to versioned IPA STU1 URLs so references don't move when IPA publishes.

Reporter(s): Aaron Mahr, Epic; Isaac Vetter, Epic
