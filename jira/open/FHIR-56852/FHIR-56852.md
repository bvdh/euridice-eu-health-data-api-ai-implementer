# FHIR-56852: Systems SHOULD support SMART Backend Services

## Description

The statement:

“Systems SHALL support SMART Backend Services authorization for all transactions.”

is too restrictive and conflicts with the need for flexibility in authorization mechanisms within the EU context. As noted elsewhere in the guide, SMART is a preferred approach but not the only possible one.

Proposed Change:

Revise the requirement level, e.g.:

“Systems SHOULD support SMART Backend Services authorization for all transactions.”

Optionally add:

“Other authorization mechanisms MAY be used, provided they comply with applicable EU regulations and trust frameworks.”
