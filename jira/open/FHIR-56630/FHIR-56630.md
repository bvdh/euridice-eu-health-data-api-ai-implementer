# FHIR-56630: Allow category-only search

## Description

Section 3.4.3.2 Document Content / Document Search Strategy

 

Issue:

The statement:

“This IG constrains type for document discovery but leaves category to content IGs and implementations.”

is too restrictive and may not reflect all valid search strategies:

	- It suggests that search by type is always required or primary

	- In practice, search by category alone (without specifying type) is also a valid and commonly used approach

	- For some use cases (e.g., Patient Summary), a single fixed type may be appropriate, but this does not generalize to all document classes

Proposed Change:

Revise the statement to allow both search approaches, e.g.:

“Document discovery may be performed using DocumentReference.type and/or DocumentReference.category, depending on the use case.

In some cases (e.g., Patient Summary), a fixed type may be used for discovery. In other cases, search by category without specifying type is also allowed.

This IG does not globally constrain DocumentReference.type; document classification SHALL be defined by the applicable content IG.”
