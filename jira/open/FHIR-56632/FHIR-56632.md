# FHIR-56632: Revise the section to clarify category-based discovery

## Description

Section 3.4.3.3.1 EHDS Priority Categories and Type Codes

	- The section does not clearly define how EHDS priority categories should be represented and used for search:

 - It does not specify whether a standardized value set should be used for DocumentReference.category

 - It does not clarify whether search across multiple categories is supported

 - It overemphasizes constraints on DocumentReference.type, which may not be necessary

Proposed Change:

Revise the section to clarify category-based discovery
