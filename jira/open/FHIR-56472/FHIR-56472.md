# FHIR-56472: Source of requirements for EHR Systems

## Description

In paragraph 2.1.1 "EHDS Annex II - Essential Requirements for EHR Systems" ([EHDS Annex II - Essential Requirements - EU Health Data API v1.0.0-ballot](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/ehds-annex-ii.html))

ANNEX II gives some of the requirements for EHR systems. But other requirements can be deduced from Articles 3, 4, 5, 7, 11, 12, 23 and 48. At the end, Implementing Acts will define the essential requirements. I suggest to change the title 2.1.1 - "EHDS Annex II - Essential Requirements for EHR Systems".
