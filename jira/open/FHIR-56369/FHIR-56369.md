# FHIR-56369: Clarify IUA vs SMART actor usage

## Description

The guide appears to introduce additional requirements for the actor labeled as an IUA Authorization Client.

SMART is the "reference" for this part when conflicts arise.

It is unclear whether an actor that includes such additional constraints can still be considered compliant with the standard definition of an IUA Authorization Client.

Clarify the actor definition by defining a separate, explicitly named actor (e.g., an ad hoc or derived actor).
