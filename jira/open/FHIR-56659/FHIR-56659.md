# FHIR-56659: Tag each IG page as Normative or Informative so implementers can identify the required-reading

## Description

Please clearly differentiate between Normative and Informative pages. This spec is big, it's well written, so there's not obvious ways to cut its length; therefore please strive to better target the absolute initially required reading for an implementer.

Proposed resolution:

Apply a per-page Normative vs Informative tag. Mechanism is a workgroup decision:

	- Page-level frontmatter / metadata rendered as a banner at the top of the page.

	- Per-section tags where a page mixes normative and informative content.

	- A "How to read this guide" page listing each page by classification.

The goal: an implementer scanning the IG can identify in seconds which pages carry conformance obligations and which are background.
