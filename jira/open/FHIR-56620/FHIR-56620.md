# FHIR-56620: Clarify formats are examples

## Description

The table describing content patterns (FHIR Document and Non-FHIR with DICOM) may give the impression that these are the only acceptable formats for document exchange. This is ambiguous and potentially misleading, as other formats (e.g., PDF, CDA, images) may also be valid depending on the use case and applicable IGs.

 

Proposed Change:

Clarify that the table provides examples rather than an exhaustive list, e.g.:

“The following table provides examples of common content patterns. Other formats may be supported depending on the use case and applicable content implementation guides.”
