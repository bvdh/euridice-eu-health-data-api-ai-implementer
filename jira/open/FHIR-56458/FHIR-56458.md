# FHIR-56458: Missing ePrescription and eDispensation

## Description

In paragraph 1.2 "Scope" ([Home - EU Health Data API v1.0.0-ballot](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/index.html)).

"This IG excludes ePrescription and eDispensation workflow transactions, user-level authorization, audit logging formats, and bulk data export."

Is there any plan to update this IG with the workflow (and the transactions) of ePrescription and eDispensation? IHE MPD covers many situation and it would be nice to cover the EHDS use cases only (Articles 3, 4, 5, 7, 11, 12, 23, 48).
