# FHIR-56648: Clarify that R5-based IGs aren't for production; implementers should target R6 (or R4 as fallback)

## Description

The R4/R5 harmonization open issue does not state a production-target FHIR version, and several priority-area dependencies point at R5-based IGs that the implementer community broadly does not recommend for production deployment. R5 IGs in this space are widely understood as preparatory for R6 — useful as design groundwork, not as a stable production target.

Make it clear in the IG that the R5 IGs aren't to be used in production environments and that implementers should develop support for upcoming R6 specifications, or, secondarily, R4 specifications. The R5 specifications simply lay groundwork for R6.

Proposed resolution:

Add a clarifying paragraph to the R4/R5 harmonization open issue (and to any priority-area page referencing an R5 IG):

	- The IG's production target is R6 (or R4 fallback where R6 dependencies aren't yet stable).

	- R5 IGs referenced here are foundational/preparatory; production implementations should prefer R6 equivalents when available.
