# FHIR-56157: missing requirements and testability

## Description

I believe the basic API IG was intended to use the IHE methodology and bring testable specifications - they are not there - and even requirements seem to be missing or scattered. As such, declaring conformance - or analysing what needs to be done to be conformant - is a difficult and uncertain exercise. Request this be made much clearer for a version 1.

Meeting notes, re: Testability

	- Charles - in order to enable testability, you need:

 - (1) setup setups - If you expect context-setting or setup setups you need to specify them. E.g. EHR system creates a patient record

 - (2) observable outcomes from the test, in a way that is simple and doesn't specify detailed functionality. Put yourself in the shoes of a monitor in connectathon, or a automated testing environment- can (2) be verified? Shouldn't be reading detailed trace files a monitor/machine should be able to evaluate

	- Testing notes in IG should support the creation of a test plan, but not fully specify the test plan. Functional outcomes.
