# FHIR-56688: DocumentReference type

## Description

In its current version, the implementation guide specifies only transaction ITI-105 for publishing health documents on an FHIR server. In addition, the implementation guide defines a DocumentReference resource as a « MinimalDocumentReference » type. However this type of DocumentReference is used in the ITI 65 Transaction defined by MHD and not in the ITI 105 as required by this implementation guide.

Proposed resolution :

Given that the implementation guide intends to specify resources compatible with transaction ITI-105, the DocumentReference resource defined must be of an appropriate type (SimplifiedPublishDocumentReference).
