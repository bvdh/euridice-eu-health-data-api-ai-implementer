# FHIR-56707: Revise Section 4.1.5.5 Step 5: Retrieve Document Content

## Description

Section 4.1.5.5 Step 5: Retrieve Document Content

The text refers to:

“using IHE MHD ITI-68 (Retrieve Document) transaction.”

This suggests use of the generic IHE transaction, while the guide defines specialized/constrained transactions. This creates ambiguity about which specification should be followed.

Proposed Change:

Update the wording to reference the transaction as defined in this Implementation Guide, e.g.:

“using the Retrieve Document transaction as defined in this guide (aligned with IHE MHD ITI-68)”
