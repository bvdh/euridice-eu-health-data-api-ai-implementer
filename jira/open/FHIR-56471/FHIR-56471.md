# FHIR-56471: Actors grouping

## Description

In paragraph 2.1.0.8.1 "API Requirements" ([Regulatory Anchors - EU Health Data API v1.0.0-ballot](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/regulatoryAnchors.html)).

"D5.1 uses "Producer" to describe the system serving the query API. This IG uses "Access Provider" to make the API-serving role explicit and avoid confusion with content creation."

It may be useful to write that the "Producer" actor can be grouped with the "Access Provider" actor. A "Consumer" actor could also be grouped with the "Access Provider". Maybe a clear definition of this 3 actors would help to undertand the basis on which this IG was created.
