# FHIR-56998: Missing support for IPA

## Description

I think the section on [https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/artifacts.html#resource-flexibility-ipa-alignment](https://build.fhir.org/ig/euridice-org/eu-health-data-api/en/artifacts.html#resource-flexibility-ipa-alignment) (section 6.0.24) should state that SMART App launch is also a MUST support. Having an API following IPA but leaving out SMART App launch seems like taking half a step.

With this specification, we as industry, need to support the needs of patient facing apps as well.
