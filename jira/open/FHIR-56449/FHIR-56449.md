# FHIR-56449: Clarify applicability of IG for NCPs and national infrastructures

## Description

This Architecture implies, that the NCPs and National Infrastructures are no EHR Systems. So EU Health Data API doesn´t apply for NCPs and National Infrastructures? Because there are a servel mismatches between [this API](https://hl7.eu/fhir/health-data-api/1.0.0-ballot/en/index.html) and the [NCP-API](https://build-fhir.ehdsi.eu/ncp-api/). Here are some examples:
