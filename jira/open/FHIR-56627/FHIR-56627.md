# FHIR-56627: Support for unstructured doc retrieval (PDF)

## Description

Section 3.4.3.1 Sequence Diagram

Issue:

The sequence diagram focuses on structured document retrieval (e.g., FHIR Document, DICOM KOS) and does not explicitly consider retrieval of binary formats such as PDF. This may give the impression that only structured formats are supported.

Proposed Change:

Update the sequence diagram to:

	- - Include retrieval of binary content (e.g., PDF via Binary resource), andor

 - Add a note clarifying that other formats are supported
