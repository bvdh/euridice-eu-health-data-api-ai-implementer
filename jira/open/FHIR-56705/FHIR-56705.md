# FHIR-56705: Revise Section 4.1.5.2 Step 2: Obtain Authorization Token

## Description

Section 4.1.5.2 Step 2: Obtain Authorization Token

The section describes obtaining an authorization token using SMART Backend Services, but it is unclear whether this approach is:

	- Mandatory, or

	- One possible option among multiple supported authorization mechanisms

This lack of clarity may lead implementers to assume that SMART Backend Services is required in all cases.

Proposed Change:

Keep the SMARTsolution as one of the possible mechanism

“SMART Backend Services is one possible mechanism for obtaining an authorization token. Other authorization approaches MAY be supported, provided they comply with the requirements defined in this guide and applicable regulations.”
