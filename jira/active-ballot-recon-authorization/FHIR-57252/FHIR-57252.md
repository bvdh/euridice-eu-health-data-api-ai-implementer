# FHIR-57252: Include FAST Security as an optional Authorization Framework

## Description

The HL7 FHIR At Scale Taskforce has released for ballot a Universal Realm version of the Security for Scalable Registration, Authentication and Authorization FHIR Implementation Guide ([https://hl7.org/fhir/uv/fast-security/2026May/](https://hl7.org/fhir/uv/fast-security/2026May/)).  This guide is the technical specification for creating a Trust Framework that is executed through the use of X.509 certificates to represent framework membership.

This can automate registration and accompanying OAuth authentication and authorization crating a tighter security domain within (and across) national networks.

While SMART on FHIR and IUA are in use, FAST Security solves the issue of scaling and removes the manual processed needed for app registration.
