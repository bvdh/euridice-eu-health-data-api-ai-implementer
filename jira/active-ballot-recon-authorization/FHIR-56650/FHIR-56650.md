# FHIR-56650: Authorization parameter SHOULDs: clarify Consumers MAY supply the same parameters Providers SHOULD support

## Description

The SHOULDs list under IUA and SMART Backend Services states Provider obligations. The corresponding Consumer obligations are implied but unstated.

Should it say "Providers MAY support [linked parameters], and SHOULD support the following parameters". I think it is implied, but Consumers MAY supply these as well (we specify Producers may support them).

Proposed resolution:

Restructure the list so Consumer and Provider obligations are stated separately. State explicitly that Consumers MAY supply the same parameters Providers SHOULD/MAY support.

Reporter(s): Aaron Mahr, Epic
