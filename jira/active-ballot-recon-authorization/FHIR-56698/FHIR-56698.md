# FHIR-56698: SMART Authorization

## Description

What is the rationale behind adopting SMART Backend Services for authorization (and the required binding with an IUA Authorization Server)? Moreover, the resource-based access scopes defined in SMART (c.f. sec. 3.5.8 Resource Access) are rather to be defined via regulatory groupings in a national infrastructure (and thus probably more coarse-grained).

Proposed resolution: References to RFC6749, RFC8414 etc. might satisfy the general requirement for authorization.
